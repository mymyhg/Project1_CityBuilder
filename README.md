# GE_CityBuilder 🏙️

A simple 3D city-builder game made in **Unity 6**, using the free
**KayKit – City Builder Bits** models (CC0).

## How to run it
1. Open **Unity Hub** → **Add** → **Add project from disk** → select this folder.
2. Press the **▶ Play** button at the top of Unity.

The game sets itself up automatically. Click a button, then click the ground to
place buildings. Move the camera with **W/A/S/D** and zoom with the **mouse wheel**.

All of the game code is in [`Assets/Scripts/CityBuilderGame.cs`](Assets/Scripts/CityBuilderGame.cs).
